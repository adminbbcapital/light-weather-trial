# Ранкова зведення для Миколаєва в Telegram

Щодня о 07:10 (за Києвом) батькам приходить повідомлення: погода, вітер, тиск,
магнітне поле, якість повітря, УФ, схід і захід сонця, графік відключень світла на сьогодні, порада дня і прогноз на завтра.
Дані: Open-Meteo та NOAA SWPC, обидва безкоштовні й без ключів.

## Налаштування (≈10 хвилин)

1. **Створіть бота.** У Telegram відкрийте @BotFather → `/newbot` → вигадайте ім’я.
   Збережіть **токен** (довгий рядок із двокрапкою).
2. **Батьки мають натиснути Start** у вашому боті (знайдіть його за іменем). Без цього бот не може їм писати.
3. **Дізнайтесь chat id.** Кожен (батьки і ви) пише боту будь-що, потім відкрийте в браузері
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` і знайдіть `"chat":{"id":123456789`.
   Це число і є chat id.
4. **Створіть репозиторій на GitHub** (можна приватний) і завантажте туди ці файли:
   `bot.py`, `README.md` і папку `.github/workflows/weather.yml`.
5. **Додайте секрети:** Settings → Secrets and variables → Actions → New repository secret:
   - `TG_TOKEN` = токен бота
   - `TG_CHAT_ID` = chat id; кілька отримувачів через кому: `111111,222222`
6. **Перевірте:** вкладка Actions → «Ранкова зведення» → Run workflow.
   Повідомлення має прийти за хвилину.

Далі воно надсилатиметься само щодня.

## Відключення світла

- У ранковому зведенні є блок «💡 Світло» з графіком на сьогодні для черги `PARENT_GPV`
  (за замовчуванням 2.1). Дані беруться тим самим кодом, що й у `outage_bot.py`.
  Якщо сайт off.energy.mk.ua недоступний, погода все одно надсилається з позначкою
  «графік недоступний». Вимкнути блок: змінна `NO_LIGHT=1`.
- Окремий бот `outage_bot.py` (workflow «Відключення світла») пише одразу, коли графік
  змінюється або відключення вмикається чи завершується. Див. `.github/workflows/README-outage.md`.

## Нагадування про лічильники

З 2 по 4 число кожного місяця о 17:00 і 20:30 за Києвом усім отримувачам приходить
нагадування передати показники лічильників з кнопкою «✅ Передали». Щойно хтось один
натисне кнопку, кнопки зникають у всіх, приходить підтвердження, і цього місяця
нагадувань більше не буде. Код: `meters_bot.py`, стан: `meters_state.json`.
Дні й години змінюються в `DAYS` і `SLOTS` на початку `meters_bot.py`.

## Перегляд без налаштувань

```
python bot.py --demo
```

Покаже вигляд повідомлення на тестових даних.

## Нюанси

- Зведення надсилає безперервний цикл бота світла (`outage.yml`) о 07:00. Запуски
  `weather.yml` за розкладом лише підстраховують. Повідомлення йде один раз на день
  (дата у `weather_sent.txt`); якщо зранку не вдалося, бот дошле його до 12:00.
- У публічному репозиторії GitHub вимикає планові задачі після 60 днів без жодних змін.
  Якщо раптом перестало приходити, зайдіть у Actions і натисніть «Enable».
- Змінити місто: `CITY`, `LAT`, `LON` на початку `bot.py`. Час: `SEND_HOUR` у `bot.py`.
- Токен нікому не показуйте і не вставляйте в код.
